# literature reading

服务于这样的阅读习惯：用户先看 AI 总结，再自行浏览论文图表；Codex 继续完成逐图导读、文献分析复述和中英对照全文，供用户回来细读。总结、导读与复述使用简体中文，保留必要的英文术语。

## 内容边界：导读可补充知识，研究分析只依文献

- 中文总结、中英对照全文，以及逐图文件中的本研究结果、分析与结论，仅以当前文章的正文、图表、图注及已取得的本篇附录/补充材料为来源。只呈现文献明确写出或标注的信息，以及作者明确表达的解释、观点和结论。
- 仅 `figures.html` 的“图表导读”允许根据文献及实际查询到的可靠资料补充读图所需的术语、符号、指标、图形表达方式及相关基础知识，帮助读者独立理解图表。补充知识需标明外部来源，并与“文献中的分析与结论”分开。不得将外部知识加入中文总结或中英对照译文，也不借导读进行独立研究评议或扩展成无关知识综述。
- 不根据文章内容自行推导结果、补全因果链、解释机制、建立图间关系或延伸应用。即使某判断看起来合理、明显或能由数据计算得到，只要作者没有明确表达，就不写入输出。保留原有数值，不自行计算差值、比例、效应量或推算图中读数。
- 不评价创新程度、证据强弱、研究质量、实验设计优劣、局限、适用边界或“该图不能证明什么”。这些内容只有在作者明确讨论时，才以作者观点复述，不追加自己的判断。
- 原文未涉及的本研究事实、结果或结论直接省略，不增设“文中未报告”“作者未讨论”“还需要验证”等条目，也不为填满固定栏目而补写。这不禁止在图表导读中补充有来源的通用基础知识。中文总结的五个固定栏目标题及导航始终保留；若原文确无某栏对应内容，正文留空，不编造内容或添加缺失说明。原文含糊之处保留其含糊程度，不用推测替作者消除歧义。
- 忠实保留作者观点的归属和语气，包括假设、推测、不确定性及作者自行作出的推论。可使用“作者认为/提出/报告”等表述，不把作者推测强化为确定事实。
- 阅读材料只包含上述各阶段允许的内容，以及必要的章节标题、页码、图号、对照标识和阅读导航控件。导航与版式可使用“阅读导航”“返回目录”等界面文字；外部基础知识限于每张图内的导读，不借导航加入学习路线或自行分析。文件链接、材料无法读取、识别不清或任务尚未完成等必要执行状态在聊天中简短说明；不可避免的缺文标记仅用于定位，不写成对文章的评论。

## 执行节奏与范围

- 默认连续完成「总结 → 逐图导读与文献分析复述 → 中英对照全文」。完成总结后立即保存为 `summary.html` 并在聊天中提供链接，再继续后两阶段；逐图文件完成后提供 `figures.html`，全文对照完成后提供 `bilingual.html`。聊天可同时呈现简短总结。不要等全部译完才给总结，也不要在阶段之间要求用户回复“继续”或确认已看完图。
- 用户明确只要某阶段、只读某些章节、改变顺序或指定格式时，按该次要求执行，不强制扩展为全流程。复用已有总结或图解时，核对论文版本，删除不符合上述来源边界的外部内容与自行判断；合法的图表导读知识和来源可保留。
- 在当前任务中持续推进，不声称后台任务已启动或会在用户离开后继续，除非实际存在这样的执行机制。
- 优先使用用户提供的 PDF、附件或全文链接。只有摘要时可以先给标明范围的摘要总结；全文或图像不可获得的部分，明确说明并请求相应材料，不虚构后续图解或全文翻译。
- 一次处理多篇时，分别组织每篇的来源、总结、图解和译文；篇数多到影响交付顺序时，再澄清优先级。

## 读取与定位原文

1. 从原材料确认论文标题、作者、年份、已有的 DOI 或链接以及所用版本，可取得同一篇文章的全文。为总结与翻译不扩充外部背景；图表导读所需的外部查询按第二阶段规则进行。读取全文结构、主要方法、结果、讨论及图注后形成总结，不将只读摘要的结果表述成全文结论。
2. 建立简明覆盖清单：章节、方法所在位置、图号及子图、表格、附录和已提供的补充材料。清单供后续防漏，不必向用户倾倒提取过程。
3. PDF 文本提取与页面图像结合使用。检查双栏顺序、跨页段落、连字、脚注及公式。扫描件可先 OCR；可疑数字、符号和图中标签回到页面核对。
4. 给重要结论与每幅图提供可回查位置，如“PDF 第 7 页，Fig. 3b”。印刷页码与 PDF 页序不同时，说明使用哪一种页码。
5. 补充材料只有在实际取得且属于本篇文章时才能纳入复述与翻译；未取得的材料在聊天中说明。文中对他篇文献的引述保留原有归属，不用外部结果重新评价或改写本研究论据。图表导读可查询其中相关的原始方法或基础概念，但仅作为单独标明来源的知识解释。

## 第一阶段：中文总结

`summary.html` 的正文一级栏目与左侧导航固定为以下五项，名称和顺序一致，不增删、改名或另设其他内容栏目：

1. **研究背景**：复述作者交代的研究背景、已有工作、问题与缺口。
2. **研究内容**：复述作者实际开展的研究、研究对象、任务与工作内容，说明研究了什么。
3. **研究方法**：复述作者采用的数据、样本、实验、模型、技术流程、对照与评价方法，说明怎样研究。
4. **研究目的**：复述作者明确提出的研究目标或拟解决的问题，不根据方法或结果反推目的。
5. **研究结论**：复述作者报告的主要发现与明确给出的结论；作者明确陈述的意义、限定条件或局限可随对应结论保留，不另设“创新”“意义”“局限”等栏目。

五栏分别使用 `summary-background`、`summary-content`、`summary-methods`、`summary-objectives`、`summary-conclusions` 作为章节锚点，导航仅链接这五栏，不追加图表目录、术语表、页码目录或原文章节目录。每栏内可有多张来源卡片，来源章节与页码放在卡片定位栏，不变成额外栏目或目录项。固定栏目是用户指定的组织方式，不将其冒称为原文章节。

每项总结均应能定位到原文表述，长度随论文复杂度调整。关键定量结论保留数值、单位、条件与原文位置，不拼凑脱离条件的数字。作者只报告相关性、提出机制假设或使用不确定措辞时，保留原有表达，不加强、不纠正、不评价其结论。

## 第二阶段：逐图导读与文献分析复述

目标是让读者只看该图及本文件就能理解图示对象、表达方式、符号和必要概念，不必反复翻查论文；对研究发现的解释与结论则完全依照文献。**先实际查看原图，再与图注、正文和相关方法核对。** 若工具无法显示或图像分辨率不足，在聊天中说明受限的图号或子图；仍可复述可读图注与正文已经写明的内容，但不能声称已经看清原图，或用外部知识猜测图中细节。

`figures.html` 的正文按每张图分别组织，一级标题与左侧导航一一对应为 `Fig. 1`、`Fig. 2` 等原文图号，顺序按原文，不自行重编号。每张图使用独立分组、来源卡片与稳定锚点，如 `fig-1`、`fig-2`；导航只列各图，不以原文章节、页码、方法或结论等主题替代图号分组。各子图的复述全部放在所属图内，保留 a、b 等原标签，不将子图拆成与整图并列的导航项。

覆盖所有已取得的正文图及其子图，包含图形摘要和独立示意图；已提供的补充图保留 `Fig. S1` 等原编号，并以各自图号作为目录项。原文确有未编号图形时，以其原有图名标识，不编造 Fig. 0 或打乱正文图号。文件仅包含各图内的导读与文献分析复述，不另外增加整篇总结、独立术语专题或表格分析一级栏目；读图所需的基础知识就近放在相应图内，表格完整内容仍纳入中英对照全文。

### 每张图内区分导读与作者分析

每张图保持原图号一级分组；组内以“图表导读”和“文献中的分析与结论”清楚分隔，沿用现有标题和正文样式，不增加侧栏一级目录。按图的类型与实际阅读需要展开，不强行套用不存在的曲线、统计检验等项目。

**图表导读**：综合图像、图注、正文、方法与必要的外部查询，解释读者理解这张图所需的信息，包括但不限于：

- **图示对象与实验语境**：本图展示什么对象、任务、实验条件、分组或对照；来自本研究的信息以文献为准，在本图内简明重述，不只写“见正文”。
- **坐标、曲线与数据点**：解释各轴变量、单位、范围、线性或对数刻度，逐条说明颜色、线型与曲线对应的对象；说明不同点形、颜色和大小编码什么，一个点在本研究中代表样本、测量、均值还是其他对象，连线或拟合线如何定义。具体映射必须来自本篇图例、图注或方法，不能按惯例猜测。
- **符号与标记**：解释箭头、阴影、误差线、置信区间、参考线、缩写和显著性符号等；区分本篇实际采用的定义与外部资料介绍的通用含义。显微图可解释通道、标记物、比例尺，示意图可解释节点、模块、连线及原文给出的流程含义。
- **必要的基础知识**：就近解释指标的定义、相关公式中符号的意义、图形或测量方法的基本原理，以及怎样按坐标、图例与编码读取这类图。可引用查询到的通用知识说明“如何读”，不得由此转而判断本图哪个方案更好、为何出现趋势或结果意味着什么。
- **逐子图对应**：保留 a、b 等原标签，分别解释各子图的图例与表达方式，避免只介绍整张图而遗漏面板。必要的术语和符号在本图内可查，避免要求读者到另一份文件寻找定义。

**文献中的分析与结论**：仅复述作者对本图或子图明确写出的实验目的、结果、解释、统计信息、结论及限定条件，并给出对应正文/图注位置。使用“作者报告/认为/解释”等归属表述，保留不确定性。作者没有作出的比较、趋势判断、机制解释、因果推断、优劣评价或结论，均不自行补充；也不从图像走势、点云分布或外部知识产生新结论。若作者没有文字分析，只保留已有图注与明确标注，不为补齐该部分而编造分析。

### 查询、来源与不确定性

- 先从本篇文献确认本图的定义与实验信息；对仍需讲解的通用概念进行有针对性的查询。优先原始方法文献、教材、标准、官方文档或权威机构资料，实际打开并核对来源，不把搜索摘要或模型记忆冒称为已查询证据。查询范围限于帮助理解该图的必要知识，不检索后续研究来修正、评价或扩展本篇结果。
- 在导读中将“本篇定义/图示信息”与“基础知识补充（外部来源）”清楚标识。外部解释就近附可追溯的文献出处或网页标题与链接，不另设侧栏的基础知识/参考资料一级目录。HTML 中保留解释正文，阅读无需联网；来源链接供需要时核查。
- 通用概念不替代本篇的自定义符号、算法、指标或实验设置。本篇专属标签无法确认时，不把查到的常见含义套在本图上；可仅介绍明确标为通用知识的定义，不声称本篇采用它。对影响读图的未确认项在聊天中简短说明，不伪装成已知事实。
- 查询不可用或找不到可靠材料时，不虚构外部来源，照实说明查询限制；先完成本篇已有信息的导读与复述。保留原数值与符号，不自行计算差值、效应量、拟合参数或补造数值示例来推演本研究结果。

尽可能在图解 HTML 中内嵌清晰的原图或完整裁图，保留标签与图例，并注明来源页码。图片采用 data URI 等离线内嵌方式，不作为单独的图片文件交付。不要重绘、补画或美化原始数据。文件大小或工具受限时，可用精确页码与图号定位，在聊天中说明没有嵌入原图。

## 第三阶段：中英对照全文

目标是可供逐段精读的完整译文，不能以中文摘要、意译大纲或图解冒充全文翻译。

`bilingual.html` 的正文结构与左侧导航按照原文目录，保留原章节、小节的编号、名称、层级和顺序。目录名称可配中文译名，但不改写成总结的五栏或图号列表。论文没有单列目录页时，使用正文实际存在的章节与小节标题构建目录；只有原文确无可靠标题结构时，才沿用 PDF 页码导航。原文图表、段落与页码仍可保留正文锚点和定位标识，但不额外生成并列的“全部图表”“核心术语”等导航分组。

### 对齐与完整性

- 默认纳入标题、摘要、正文各节、方法（包括位于文末的方法）、结论、图题图注、表格及表注、脚注、致谢、声明和已提供的附录/补充材料。参考文献保留原始书目信息及编号，默认不逐条翻译；任何未纳入部分均在聊天中说明。
- 保留原章节次序和段落层级，按“英文原文 → 中文译文”一一配对。默认以段落为单位，不把多个原段合并成一个概括译文。长段落只有在对应关系清楚时才拆分。
- 为段落设置稳定标识，并记录来源章节或 PDF 页码；跨页段落可标页码范围。图号、表号、公式号及文内引文保持一致，方便在图解、译文和原论文间回查。
- 修复明显的排版断词、重复页眉页脚与提取顺序错误；不得借“修复”改写英文论述。无法可靠辨认的片段保留定位并标记“原文识别不清”，不要自行补全。
- 表格保留行列对应、数值、单位及注释，可在同一单元格中保留英文并附中文。图注完整对照，不能只翻译图题。图内英文标签必要时另列对应译名，原图保持原样。

### 翻译忠实度

- 准确保留否定、比较方向、条件、时态所表达的研究事实和 may/suggest 等不确定程度；不把“提示”升级为“证明”。
- 保持专业术语一致；关键术语首次出现采用“中文（English，缩写）”，后续使用一致译法，缩写仅在原文给出时保留。若整理术语表，只列原文出现的词语与对应中文译名，不添加文章未给出的定义或背景。
- 保留基因/蛋白命名、化合物名、模型名、缩写、数字、单位、上下标、希腊字母、公式及引用关系。公式中的符号不擅自汉化，公式后解释可译。
- 不添加译者的阅读提示、背景补充、疑点、评述或推导，即使单独标为“译注”也不加入。原文作者自己的注释正常翻译并保留归属。

### 对照布局

中英对照全文使用与总结、逐图复述相同的 HTML 样式规范。每对段落放在独立的暖白色 `.reading-card` 中，顶部 `.card-meta` 标注段落标识和来源页码，下面为 `.parallel-row`，其内分别是 `.parallel-cell[lang="en"]` 与 `.parallel-cell[lang="zh-CN"]`。宽屏左英文、右中文，窄屏同段先英文后中文。不得将整篇英文与整篇中文各放在一个独立长栏，以免段落失去对应。卡片再按原文节或页分组，使用侧边栏目录、段落锚点和图号定位。

公式采用可离线显示的方式；复杂公式无法可靠排版时，内嵌带编号的原图或保留可读公式文本，不以排版结果掩盖识别错误。

## 全部交付文件使用统一 HTML 排版

- 总结、逐图复述、中英对照全文及额外生成的阅读材料均交付为 UTF-8 `.html`，不自动降级或另行交付 Markdown、Word、PDF、纯文本、独立 CSS、图片或脚本。内部提取与检查的临时文件留在工作目录；原始论文是输入，不受此交付格式限制。只有用户后续明确要求改变格式时才调整。
- 每个 HTML 都是能独立离线打开的完整文档，具有 `<!doctype html>`、`<html lang="zh-CN">`、UTF-8 字符集及 viewport 设置。CSS、图片和必要的公式资源内嵌，正文显示不依赖 CDN、网络字体或另一个文件；若实际环境受限，说明具体限制，不偷偷换格式。
- 生成任一文件前读取 [assets/reading.css](assets/reading.css)，将其原样内嵌到 `<style data-literature-reading>` 中。三个阶段使用完全相同的这份 CSS，不各自设计样式，不通过额外样式表、内联 `style` 或脚本覆盖排版。若同次阅读中用户指定排版修改，在任务工作目录建立这一 CSS 的统一副本，修改该副本并同步内嵌到全部文件，包括已交付的阶段文件；不因此修改已安装的 skill 或交付独立 CSS。
- 每次生成 HTML 前读取 [references/layout.md](references/layout.md)，按其中的 DOM 结构组织 `.reading-shell`、侧边栏和 `<main class="reading-document">`。三个文件统一采用暖纸学术风格，以米白背景、暖白纸面卡片、墨色正文和低饱和松绿构成视觉层次；用细边框、轻阴影、舒展留白和淡鼠尾草色来源栏组织长文。总结和逐图复述的卡片内使用单栏，全文对照的卡片内使用逐段双栏；同级标题、正文、图注与表格的文字样式不变。
- 各文件的“阅读导航”始终固定在屏幕左侧，包括窄屏；不得移到页面顶部、右侧或正文上方。长目录在左侧栏内独立滚动，正文在右侧预留导航宽度和栏间距，滚动与锚点跳转时均不被导航遮挡。窄屏仅收窄左栏和栏间距，目录仍可在左栏内折叠，不改变其位置。目录支持原生锚点跳转、键盘操作，并提供“返回目录”。不需要联网或脚本才能使用基本导航。
- 三个文件使用各自固定的组织规则：总结为上述五栏、逐图复述为原文各图号、中英对照为原文目录；不得混用目录模板。各组仍保留来源章节、页码、卡片分隔与留白，跨页段落和中英段落对不得为分页而拆散，来源标为页码范围。中英对照的长章节可在内部按原页进一步分隔，但有原文目录时不因此添加新的一级导航项。
- 总结五栏内的来源卡片、各图内的来源卡片以及全文对照的原文节/页卡片保留各自定位，涉及多个章节的条目不虚构一一归属。目录仅链接本文件实际存在的目标，包括总结中按要求保留的五栏标题；不照抄参考截图中的论文标题、栏目或术语，不链接尚未生成的文件。

### 三份阅读材料互相跳转

- 同一篇论文的 `summary.html`、`figures.html`、`bilingual.html` 保存在同一目录。每份页面均在 `<main>` 内的标题卡片顶部放置统一的“阅读材料”切换导航，按“论文总结 → 图表解释 → 中英对照”的固定顺序展示三个入口，形成连贯的阅读文档。
- 切换导航使用 `<nav class="document-switcher" aria-label="阅读材料">`，沿用统一 CSS；当前页面用带 `aria-current="page"` 的文本标识，另外两份已生成的页面使用原生 `<a>`，分别链接 `summary.html`、`figures.html`、`bilingual.html`。链接使用同目录相对路径并在当前标签页打开，使整目录移动后仍可离线互跳。
- 按阶段交付时，尚未生成的页面入口显示为普通文本；每完成一个阶段，立即将新页面与此前已交付页面中的对应入口更新为有效链接。全流程完成后，三个页面各自都能一键跳转到另外任意一份。用户只要求部分阶段时，仅为本次实际生成的阅读文件提供入口。
- 页面切换导航与左侧的本页目录各自组织；本页目录继续遵循总结五栏、原文图号、原文章节的既有规则。具体 DOM 示例见 [references/layout.md](references/layout.md)。

## 长文与交付检查

- 长论文按章节持续写入文件，维护章节/图表/段落覆盖记录与术语表，避免上下文切换导致漏译或重译。不因单次消息长度限制改成交付摘要，也不将部分译文标为全文完成。
- 若受实际执行限制无法一次完成，交付已完成文件，明确已覆盖章节、尚未完成部分及续接位置；不得暗示后续已经完成。
- 交付前对照覆盖清单核查：各图及子图均已覆盖其图示、导读和作者已有的分析，没有用自行推导补齐本研究结果；各原文段落都有对应译文；方法、图注、表格与补充材料无静默遗漏；重点核对数值、单位、否定词、公式编号和引文。
- 分别核查来源边界：总结、译文以及各图的本研究事实和作者分析须有本篇明确出处；图表导读中的外部基础知识须有实际核实的来源，并清楚标记为补充知识。不得因其来自外部就删掉合规导读，也不得把外部定义冒称为本篇采用的定义。删除自行计算、推断、评价、文章未涉及研究事项的清单及译者观点，防止把“怎样读图”写成“本图证明了什么”。
- 对每张图检查：曲线、数据点和符号的具体含义能追溯到本篇图例或方法；必要术语可在本图导读内找到；外部知识与作者分析已分开，未用补充知识解释本研究趋势、判断优劣或产生结论。作者没有文字分析的部分没有补写成新的研究结论。
- 检查正文一级分组与侧栏目录完全对应：总结恰为“研究背景、研究内容、研究方法、研究目的、研究结论”五栏且顺序固定；逐图复述逐一对应原文各图号，子图未与整图并列；中英对照目录与原文章节编号、层级及顺序一致，未混入其他文件的栏目。缺少原文依据时不为填满栏目补写内容。
- 检查各页面标题卡片中的切换导航，当前页标识正确，链接指向同篇论文同目录下的已生成文件。完整交付时，从每份 HTML 分别点击另外两个入口，确认六个方向均能在当前标签页打开目标主页面，离线打开同样有效。
- 抽查英文配对是否仍为原文、中文是否准确；核对重要定量结论与原页面。对 HTML 检查长段落、长表格、公式、内嵌图片、离线打开和窄屏对齐；并排检查三个文件的主标题、章节标题、正文段落、图注和表格，核对它们使用同一 CSS 且没有局部排版覆盖。具备浏览器预览能力时，核对实际计算出的字体、字号、缩进、对齐和行高，避免被浏览器默认样式干扰。另检查目录中的全部锚点均存在且唯一、顺序符合各文件的固定规则，章节/页码分组没有割裂段落对；所有屏宽下导航都固定在屏幕左侧且不遮挡右侧正文，窄屏可在左栏内折叠并且页面没有整体横向溢出，长表格仅在其容器内横向滚动。不能实际检查的项目如实说明。
- 在用户指定目录或当前环境的交付目录保存三个 HTML：`summary.html`、`figures.html`、`bilingual.html`；多篇论文使用各自子目录，额外阅读材料也为 HTML。最终只链接这些 HTML 阅读文件及说明覆盖/缺失情况，不链接内部中间文件，不重复粘贴整篇译文。
