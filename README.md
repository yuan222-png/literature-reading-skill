<a name="仓库简介"></a>

## 📚 仓库简介

Literature Reading 将英文科研论文整理为中文总结、逐图复述和中英对照全文，帮助中文读者从了解研究内容逐步进入原文精读。

提供论文 PDF、附件或全文链接后，Skill 会先交付中文总结，再继续整理图表和对照译文。你可以先阅读总结、自行浏览原图，再结合逐图复述和对照全文细读论文。完整指令见 [SKILL.md](skills/literature-reading/SKILL.md)。

<a name="skill-解决的问题"></a>

## 🎯 Skill 解决的问题

| 阅读中的需求                      | Skill 提供的支持                                                               |
| --------------------------------- | ------------------------------------------------------------------------------ |
| ⚡ **快速了解一篇论文的研究内容** | 整理研究问题、方法、主要结果，以及作者明确讨论的贡献与局限。                   |
| 🔍 **对照正文理解复杂图表**       | 按图号和子图逐一复述标注、实验对照、统计信息及作者给出的解释，并保留原文定位。 |
| 📑 **逐段阅读英文长文**           | 配对呈现英文原文与中文译文，保留章节、图注、表格、公式和文内引用。             |
| 🧩 **区分论文表述与额外解读**     | 将输出限定在论文及已取得的本篇补充材料内，保留作者观点的归属、推测和不确定性。 |

所有阶段均以原文明确写出或标注的信息为依据。原文数值与措辞强度保持一致，未涉及的信息直接省略。

<a name="skill-的工作流程概要"></a>

## 🧭 Skill 的工作流程概要

### 1. 📝 中文总结

读取论文正文、主要方法、结果、讨论和图注，先在聊天中交付中文总结，覆盖文章明确涉及的研究问题、研究设计、主要发现、作者讨论的局限和图文对应。

重要结论附原文位置，便于回查。总结与复述使用简体中文，并保留必要的英文术语。

### 2. 🔬 逐图与子图复述

查看原图，并与图注、正文和相关方法核对。按原始编号整理各图及子图的分组、对照、坐标、图例、统计信息和作者结论，已提供的补充图单独列出。

图解文件尽可能保留清晰原图，并标注来源页码。文件可用后提供阅读链接。

### 3. 🔤 中英对照全文

按原章节顺序逐段配对英文原文和中文译文，覆盖正文、图注、表格、公式及已提供的附录与补充材料。参考文献保留原始书目信息和编号。

默认交付可离线阅读的 HTML，宽屏左右对照，窄屏按段落先英文后中文排列，并提供章节目录、段落锚点和图号定位。总结与图解可分别保存为 Markdown。

默认连续完成以上三个阶段，也可以按需指定某个阶段、章节、执行顺序或 Markdown、Word、PDF 等交付格式。
